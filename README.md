# NEON ROYALE 🎮👑

Онлайн-битва 1 на 1 в стиле Clash Royale: перетаскивай карточки героев на неоновую арену, разрушай башни соперника, поднимайся в таблице лидеров.

**Разработчик:** ИП Снегирёв Иван · [Группа ВКонтакте](https://vk.ru/club240566635)

## Что в репозитории

| Папка | Что это |
|---|---|
| `server/` | Игровой сервер (Bun + Socket.IO) — матчасть для Railway |
| `client/` | Исходник приложения (Next.js, статический экспорт + Capacitor для APK) |

## Возможности игры

- ⚔️ **26 карточек**: 17 героев + 5 башен-строений + 4 секретные лисьи карты
- 🗼 **7 скинов башен** (покупаются за золото в магазине, лисья — только секретный код)
- 🏆 **Таблица лидеров** (топ-100 на сервере), уникальные ники
- 🤖 Боты играют героями и строениями, есть соперничество
- 🛒 Магазин: герои, башни-карты, скины, усиление башен
- 🎟️ Промокоды (проверяются **только на сервере**, в клиенте кодов нет)
- 🔒 Ник + очки — не персональные данные (152-ФЗ), уведомление РКН не требуется

## Деплой сервера на Railway

1. В Railway: **New Project → Deploy from GitHub repo** → выбрать этот репозиторий.
2. Корневая директория сервиса: `/server` (Railway определит Nixpacks + Bun автоматически; конфиг — `server/railway.json`).
3. Порт: сервер слушает `PORT` Railway автоматически (или `GAME_PORT`, по умолчанию 3003).
4. (Опционально) подключи Volume на `/data` — тогда ники, трофеи и золото игроков переживут перезапуски. Без Volume данные живут в папке сервиса.
5. Домен Railway → этот адрес уже вшит в клиент (`client/src/hooks/use-neon.ts`, константа `SERVER_URL`). Если домен изменится — поменяй константу и пересобери APK.

### Запуск локально

```bash
cd server
bun install
bun index.ts          # порт 3003
```

## Сборка APK (клиент)

```bash
cd client
bun install
NEXT_PUBLIC_DEFAULT_SERVER=https://<твой-railway-домен> bun run build   # статический экспорт в out/
npx cap sync android
cd android && ./gradlew assembleDebug
```

- Пакет: `ru.neonroyale.game`
- Полноэкранный режим (immersive sticky, скрытие статус-бара) — `MainActivity.java`
- Подпись выпуска: отдельный keystore (не в репозитории)

## Промокоды

Коды хранятся на сервере в XOR-обфусцированном виде и выдаются только через событие `r:promo` (лимит 5 попыток в минуту):

- Обычные коды — золото (одноразовые для профиля)
- **Секретный админ-код** — открывает 4 лисьи карты + башню «Лисье логово» + выбор лисьих скинов

> Админ-код знает только разработчик. В APK и в клиенте его нет — при декомпиляции приложения его не найти; передача по HTTPS/WSS не даёт перехватить ответ сервера.

## Протокол сервера (r:*)

`r:login` (уникальные ники) · `r:leaderboard` · `r:queue:start/cancel` (поиск пары, 13.5с → бот) · `r:match:start` · `r:state` (10 Гц) · `r:deploy` (серверная валидация эликсира и зоны) · `r:shop` (все покупки на сервере) · `r:deck:save` · `r:cosmetics` · `r:promo` · `r:rejoin` (возврат в бой после обрыва) · `r:battle:leave`

## Право и приватность

- Собираются только: самодельный ник, анонимный UID (генерируется на устройстве), игровые показатели.
- Политика конфиденциальности и пользовательское соглашение — в настройках игры (редакция от 9 ноября 2026 года).
